## Where this came from

Derived from Loan Factory marketing source material supplied for this project — see
[`../../docs/provenance.md`](../../docs/provenance.md). The **operational logic** was
extracted and generalized. Raw content libraries, exact DM and email scripts, and full
prompt libraries were deliberately **not** copied, on the instruction of the source
material's own `DO_NOT_IMPORT` guidance.

## How skills use it

A skill references the knowledge file instead of restating it:

> Apply the content mix in `knowledge/marketing/content-strategy.md` and the guardrails
> in `knowledge/marketing/marketing-compliance.md`.

This keeps `SKILL.md` files short and keeps one source of truth for each idea.

## Customizing

These are defaults, not rules from on high. Your team's voice, cadence, and mix are yours.
Change them here, or override per Loan Officer in `config/marketing.yaml`.

Compliance content is the exception: loosen it only with your compliance department, not
because it is inconvenient.
