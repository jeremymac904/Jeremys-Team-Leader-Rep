# Prompt library

Prompts for the situations that come up between the scheduled work.

**How this differs from [`../automations/`](../automations/):** the automation catalog is
for recurring workflows on a cadence. This library is for the one-off — a conversation you
have to have this afternoon, a decision you are stuck on, a piece of content you need now.

Each prompt tells you what to supply. Fill in the `[brackets]` and paste.

## Getting better output

1. **Give it the numbers.** "Jordan is struggling" produces generic advice. "Jordan: 96
   conversations, 1 appointment, 0 applications" produces a diagnosis.
2. **Say what you already ruled out.** Stops it re-suggesting what you tried.
3. **Ask for the constraint.** "Give me one thing" beats "give me ideas."
4. **Push back.** "That is generic — which of these actually applies to a 5-month LO?"

## Before you paste

Strip anything you would not want in a screenshot: borrower names, account numbers, SSNs,
credit data, income documents. Team members' first names are usually fine; borrower
identities are not. See [`../docs/privacy.md`](../docs/privacy.md).
