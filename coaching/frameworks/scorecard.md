# The scorecard

One page. Five to eight numbers. Filled in daily, reviewed weekly.

## Why five to eight

Below five, you cannot see where the funnel breaks. Above eight, nobody fills it in — and a
scorecard nobody fills in is worse than no scorecard, because it produces the illusion of
measurement.

## The core set

| Metric | Why it earns a slot |
|---|---|
| Income blocks honored | The single best leading indicator. If this is zero, nothing else matters. |
| Calls or touches | Raw effort |
| **Real conversations** | Two-way conversations, not dials. This is the number that predicts. |
| Appointments set | The asking behavior |
| Appointments held | Confirmation discipline |
| Applications | Consultation effectiveness |
| Pre-approvals | Pipeline being built |
| Reviews or referrals asked | The compounding habit almost everyone skips |

## Add-ons for experienced producers

Established LOs and top producers need different numbers, because activity volume stops
being their constraint:

- A-tier partner touches
- Content shipped
- Database reactivation touches
- **Weakest conversion ratio this week** — the single most useful line on an experienced
  producer's scorecard

## Reading it as a leader

1. **Blocks honored first.** If blocks are zero, stop. Everything else is downstream and
   coaching skill this week would be wasted.
2. **Then the ratios**, not the totals. Totals tell you effort; ratios tell you skill.
3. **Then the trend.** One week is noise. Three weeks is a pattern. Do not intervene on
   noise — you will train the team to hide numbers.

## Make honesty cheap

The scorecard fails the moment it becomes a report card. If a bad number produces a bad
conversation, LOs will inflate. Respond to a bad number with curiosity — "what happened
Tuesday?" — and you will get accurate data, which is the only kind worth having.
