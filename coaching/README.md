# Coaching system

The coaching material is split in two:

- **[`frameworks/`](frameworks/)** — the reusable methods. How to diagnose a Loan Officer's
  real problem, how to run the weekly rhythm, what to say in the hard conversations. These
  are yours to use and edit.
- **[`../templates/`](../templates/)** — fill-in templates for the artifacts you produce:
  development plans, accountability reviews, business plans, meeting agendas.

Your actual coaching notes about actual people do **not** go here. They go in `team-data/`,
which is gitignored. This directory is the method; `team-data/` is the record.

## The frameworks

| File | What it covers |
|---|---|
| [`diagnosis.md`](frameworks/diagnosis.md) | Find the broken funnel stage before prescribing a fix |
| [`weekly-rhythm.md`](frameworks/weekly-rhythm.md) | Theme days, time blocks, and the leader's own week |
| [`scorecard.md`](frameworks/scorecard.md) | The 5–8 numbers worth tracking, and why more is worse |
| [`coaching-conversations.md`](frameworks/coaching-conversations.md) | Session structure and the four hard conversations |
| [`follow-up.md`](frameworks/follow-up.md) | Cadences by situation, for LOs and for partners |
| [`scripts.md`](frameworks/scripts.md) | Practice scenarios and script structure for role-play |
| [`partner-strategy.md`](frameworks/partner-strategy.md) | Building and keeping referral relationships |

## The one idea underneath all of it

**Coach the activity before judging the result.** Results are lagging and mostly outside
the Loan Officer's direct control in any given week. Activity is leading and entirely
within it. A leader who manages results creates anxiety; a leader who manages activity
creates production.
