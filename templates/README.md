# Templates

Fill-in artifacts. Copy one into `team-data/` before you fill it in — anything with a real
person's name on it does not belong in a tracked folder.

```bash
cp templates/weekly-scorecard.md team-data/scorecards/jordan-2026-w34.md
```

| Template | Use |
|---|---|
| [`weekly-scorecard.md`](weekly-scorecard.md) | The weekly numbers, per Loan Officer |
| [`one-on-one-prep.md`](one-on-one-prep.md) | Before a coaching session |
| [`coaching-recap.md`](coaching-recap.md) | Same-day session record |
| [`development-plan.md`](development-plan.md) | 30/60/90 ramp, recovery, or growth plan |
| [`team-meeting-agenda.md`](team-meeting-agenda.md) | Weekly meeting |
| [`accountability-review.md`](accountability-review.md) | The standards check |
| [`lo-business-plan.md`](lo-business-plan.md) | Quarterly or annual LO plan |
| [`recruiting-candidate.md`](recruiting-candidate.md) | Candidate record and interview notes |
| [`partner-profile.md`](partner-profile.md) | Referral partner record and value plan |

Most of these can also be produced by the agent — ask for the skill named in each file's
header and it will fill the template from your data.
